Purple Python README + Showcase Outline
Purple Python
Purple Python Relay
A live multi-mind relay system for connecting independent AI interfaces and passing conversation between them under human direction.
Purple Python Relay does not require the connected AI systems to share an API or use the same platform. It works through their native web interfaces and coordinates them as participants in a live conversational relay.
The result is a system where different AI minds can receive, respond to, and build upon one another's messages in sequence.
Purple Python Player
Purple Python Player is the companion interface for playing, reviewing, and navigating recorded relay sessions.
Together:
Purple Python Relay connects the minds.
Purple Python Player plays the record.
The system is built around state-machine behavior rather than treating the relay as a simple stream of text.
Showcase
Purple Python — Multiple AI Minds, One Conversation
What happens when you connect several independent AI systems into one live conversation?
This video demonstrates Purple Python Relay connecting multiple AI interfaces and passing their responses through a human-directed relay.
You'll see the relay operate live, with each participating AI responding through its own native interface.
Then we'll use Purple Python Player to review the resulting session.
No single AI is pretending to be the others.
They are separate systems.
Purple Python simply gives them a way to talk.
The Basic Idea
Human → Purple Python Relay → AI → AI → AI → Human
Each participant remains its own system.
Purple Python provides the connective machinery.
