Here are the easiest ways to grab links and paths right from the GitHub web UI:

1. Copying the URL for a Folder or Directory Path

From the Browser Address Bar: Simply navigate into the folder (e.g., archive/MMRC_ARC_Aug 29 2026 01_22_40_AM) and copy the full URL straight out of your browser’s address bar.

Copy Path Name Only: At the top of the file list on GitHub, click the small breadcrumb path (e.g., QuackSink / archive / ...). You can highlight and copy the plain text folder name right off the screen.

2. Copying the URL for an Individual File

Browser Address Bar: Click on the file name to open it, then copy the URL directly from the address bar.

The "Y" Key Shortcut (Best for Permanent Links): While viewing any file on GitHub, press the y key on your keyboard. GitHub will instantly convert the URL in your address bar into a permalink tied to that exact commit SHA. Copying that URL ensures it never breaks even if files are updated later!

The "..." File Menu: On the top-right corner of the file viewer (next to "Raw" and "Download"), click the three dots (...) and select Copy permalink or Copy path.

3. Copying Raw File Content (For Direct Code/Log Reading)

When viewing a file, click the Raw button near the top right. This opens a plain text version in your browser, and you can copy that direct raw URL (e.g., [raw.githubusercontent.com/](https://raw.githubusercontent.com/)...).

Drop whichever link or relative path you grab right into our thread!
