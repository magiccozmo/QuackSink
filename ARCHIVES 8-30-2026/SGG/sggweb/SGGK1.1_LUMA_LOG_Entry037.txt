Baseline: SGGK1.0, exact source archive retrieved from repository main commit 4a55fbf2e75a0fcb074e555903ead3f5f9a41b3f.

PURPOSE

Correct the Little Lantern runtime failure reported during Cozmo's K1.0 field test. Both entering through the Front Gate door and fast-travelling to The Little Lantern produced a blank browser game window.

ROOT CAUSE

The two routes were not independently broken. Both routes correctly reached the same Little Lantern area renderer. Three line-drawing commands in the little_lantern_interior Luma Draw Engine recipe had malformed nested RGB values:

- Command 276: [[222, 186, 123]]
- Command 277: [[211, 155, 97]]
- Command 278: [[204, 131, 87]]

The renderer expects a flat RGB/RGBA sequence and converts each component to an integer. It instead received a list as a colour component, raising a TypeError while rendering the area. This explains why both the door and fast-travel entry paths failed at the same point.

IMPLEMENTATION

- Changed only those three colour values to [222, 186, 123], [211, 155, 97], and [204, 131, 87].
- Updated the game version and global-session identity from SGGK1.0 to SGGK1.1.
- Added validate_luma_assets.mjs to check each Luma Draw Engine recipe, supported drawing operation, and flat integer RGB/RGBA colour array before release.
- Retrieved and included the corrected shared Global Usage Worker source. Its version validator accepts the SGG[A-Z] edition family rather than only SGGG. Cozmo had already deployed this Worker and confirmed that new sessions now record.
- Updated the current-edition catalog and the visible Browser Edition Archive version marker to SGGK1.1.

PRESERVATION

The Little Lantern area geometry, background recipe apart from the three corrected colour fields, door objects, reciprocal door connections, fast-travel destination, all 23 areas, 44 connections, 68 world objects, 12 NPCs, dialogue, collision, navigation, and save schema remain unchanged. No later Grella quest content was added. K1.0 remains preserved as the previous selectable edition; all earlier release directories are retained.
