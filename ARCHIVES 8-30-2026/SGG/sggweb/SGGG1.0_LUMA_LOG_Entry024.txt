GLOBAL USAGE LOG

- G1.0 registers an anonymous session with the existing Worker after difficulty selection. The Worker generates a temporary session ID and supplies UTC timestamp and approximate country.
- Selected gameplay milestones are submitted asynchronously; network failures never pause gameplay.
- Active-minute heartbeats are emitted no more than once per minute, and only when player input or movement occurred during the preceding minute. Idle/background time is not counted.
- The private Local Session Log opens with L; L is rebindable under Configure Keys. The latest event remains visible below the help line when contextual hints are toggled off.
- The front page has a GLOBAL LOG link and anonymous-tracking notice. The public page reads the spoiler-safe activity feed. Test-version sessions are hidden from its display.
- Cozmo encounter counting includes both current exploit cameo message forms, HELLgs hint cameos, and the special scenic-overlook Cozmo appearance. Public labels remain numbered and spoiler-safe.
- Worker update script GLOBAL_LOG_WORKER_SGGG1.0.js is included in the source package. It adds approved public labels, numbered area discoveries and Cozmo encounters, one-per-session achievement guards, per-session event throttling and offset paging. It must be deployed manually to the existing Worker before public playtesting. D1 schema is unchanged.

GAMEPLAY CHANGE — TROLL CAVE

- Easy retains fast travel to and from all ordinary areas, including Troll Cave.
- Normal retains fast travel TO discovered areas and FROM ordinary areas, except that fast travel FROM Troll Cave is blocked.
- Normal-mode message: “No fast travel allowed from here... this ain't EASY mode.”
- Spiffy Challenge retains the existing no-fast-travel behavior.
- Pineapple Getaway is recorded only when the player leaves Troll Cave while still carrying or possessing the Purple Passion Pineapple. Walking out counts; Easy-mode fast travel out also counts. Picking up the pineapple or merely waking Frosty does not count. It is limited to once per session.

OTHER SELECTED MILESTONES

- Six existing Cozmo Tea exploit achievements are mapped to spoiler-safe public labels.
- Quest, crafting, soup, carriage, scenic-overlook, area-discovery, HELLgs challenge-start and HELLgs game-over milestones are included.
- No player names, account IDs, inventory contents, detailed coordinates, arbitrary dialogue or private detailed Player Log entries are sent to the public feed.
