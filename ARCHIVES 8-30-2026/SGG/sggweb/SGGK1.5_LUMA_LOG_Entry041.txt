THE RIVER IS NOW FIELD-CONFIRMED
Cozmo supplied a K1.4 flight recorder session from November 7, 2026. It verifies Grella's recruitment, Giant Camp panic, flee to the River, Tea and Cozmo cameo, player entry to Mudcrab River, movement inside it, and return to Plains. K1.5 starts from that exact K1.4 release. The player's River transition repair is retained.

GRELLA'S CHEWED CORPSE
The earlier K1.3/K1.4 runtime did not contain a corpse object or interaction handler, despite Entry039's misleading note that the behavior had been carried forward. K1.5 implements the missing mechanic explicitly. When Grella is taken by the mudcrabs, a separate, non-takeable "Grella's Chewed Corpse" object is created in Mudcrab River, centred at the recorded encounter position (240,485). The artwork is a deliberately cartoonish, non-graphic bundle of bonnet, apron and muddy limbs. The object can be selected with the mouse and examined with E; a visible prompt identifies the action.

GRELLA MK 2
Examining the remains consumes the corpse object and spawns a distinct NPC, Grella Mk 2, at the River. She uses Grella's established character artwork but a separate NPC identity. Mk2 never enters the follower system and _talk ignores her, so she does not converse with the player. A save-persistent route stage moves her silently through the existing route: Mudcrab River -> Plains -> Stables -> Outside Gate -> Front Gate -> The Little Lantern. She finishes at Grella's original home position (405,440), quietly rejoining the children.

OUTCOME AND SAVE RULES
- If Grella reaches the River first, the existing one-time Tea reward and Cozmo cameo remain unchanged; the body appears.
- If the player reaches the River first, the existing player-first outcome remains unchanged: Grella escapes, and no corpse or Mk2 is created.
- Interacting with the corpse removes it and can spawn Mk2 only once.
- The corpse position, removed marker, Mk2 identity, route stage and returned marker live in the existing saved object/NPC/c1_flags state. No save reset or schema bump is introduced.
- Older K1.4 saves with Grella already dead but no corpse are migrated by creating the missing body in Mudcrab River. A save that already records corpse removal is not resurrected.
