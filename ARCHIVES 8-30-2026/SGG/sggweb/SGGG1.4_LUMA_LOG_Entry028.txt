SGGG LUMA LOG — ENTRY 028
Date: 2026-11-06
Release: SGGG1.4
Baseline: SGGG1.3; all earlier source and log history preserved.

G1.4 PURPOSE
This release addresses the remaining Global Log/privacy and save-state requirements identified during Cozmo's SGGG1.3 field test. The deployed version selector is intentionally lean: original legacy editions, SGGG1.3, and SGGG1.4 only. Historical G1.0, G1.1 and G1.2 source/release material remains in the source archive, not the public playable deployment.

PLAYER PRIVACY
- The front page carries the selected location choice into the game using both an explicit sgg_location URL parameter and same-tab sessionStorage.
- NONE OF YOUR BUSINESS stores the local choice as anonymous, clears the preview fields, and prevents another location lookup during that front-page visit.
- The browser bridge defaults to ANONYMOUS when consent is missing, unknown, or unavailable. An explicit share choice is required before country/city can be recorded.
- The Worker still trusts only Cloudflare request metadata when sharing is explicitly true; opt-out sessions store the literal ANONYMOUS value and no country/city.

SAVE/LOAD AND DIFFICULTY
- Successful saves create a public Global Log event labeled Game Saved. Failed saves do not create an event.
- Successful loads create a public Global Log event labeled Save Loaded. Failed or empty-slot loads do not create an event.
- Loading a save restores the saved world and save-bound Tea ledger but never changes the difficulty selected for the current run.
- During inherited load processing, the current run difficulty remains authoritative for HELLgs runtime-flag handling. This preserves the cross-version HELLgs escape exploit. The restored world flags and machine preference are reconciled to the current run difficulty after a successful load.
- Save/load events do not award Tea or alter achievements.

HUD AND RELEASE PAGE
- The in-game top status line now shows DIFF: EASY, DIFF: NORMAL, or DIFF: SPIFFY CHALLENGE at the far right. It reports the active run difficulty, not a value read from the loaded save.
- The front page eyebrow now reads Britrun · Browser Edition Archive SGGG1.4.
- The front page version selector contains only the eight preserved legacy editions, SGGG1.3, and SGGG1.4.

PRESERVATION
- SGGG1.3 remains an unchanged playable edition.
- Older G1.0/G1.1/G1.2 directories are omitted only from the lean Cloudflare site ZIP; their source folders and historical records remain in the full source ZIP.
- The source ZIP keeps its prior archive history; the site ZIP carries all legacy versions plus G1.3 and G1.4.
- No GitHub main content was changed, no Cloudflare deployment was performed, and no D1 migration is required.

VALIDATION
Static validation covers Python syntax, Worker JavaScript syntax, landing-page and bridge consent handoff, release labels, version catalogue contents, identical runtime mirrors, tar/APK contents, and ZIP integrity. Live browser/Cloudflare field testing remains for Cozmo.
