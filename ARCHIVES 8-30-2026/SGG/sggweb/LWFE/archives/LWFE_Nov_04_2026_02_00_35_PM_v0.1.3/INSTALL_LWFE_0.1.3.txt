Allow Windows to merge the included LWFE folder and replace the matching source files.

Start from a normal Windows CMD window:
cd /d "D:\QuackSink\ARCHIVES 8-30-2026\SGG\sggweb\LWFE"
py -3 lwfe_app.py

On each launch, LWFE creates a new timestamped directory under archives.

creation fails, rendering is disabled rather than falling back to the
main LWFE/sounds folder.
